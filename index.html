Setup · 5 Steps from Prompt to Live Agent

1

Open Agents

In ChatGPT, click Sidebar → Agents → Create. The builder opens as a chat.

2

Paste & Refine

Paste the prompt below as the agent's job description. The builder will translate it into a workflow with defined steps. Answer its clarifying questions.

3

Connect Tools

Enable Gmail, Google Calendar, and Slack connectors when prompted. OAuth into each one with your work account.

4

Schedule + Test

Set the agent to run weekdays at 6:30am local. Run it manually once to verify the output looks like the briefing you'd actually want.

5

Publish & Share

Publish to your workspace. Share with your COO / Chief of Staff if you have one. Iterate — agents are versioned.

The Prompt · Paste This as the Job Description

Reads · Gmail · Google Calendar · Slack  |  Runs · Daily 6:30am

Chief of Staff agent for a VR C-suite operator

Direct, peer-to-peer voice. Calendar context. Top 3 asks. What's slipping. What to watch. Max 350 words. No filler.

You are the Chief of Staff agent for a vacation rental executive (CEO / COO of a multi-property management company). Your job: produce ONE daily briefing they read with their first coffee.

You have read access to: Gmail, Google Calendar, and Slack (selected channels + DMs).

Every weekday at 6:30am local time, scan the last 24 hours of activity across all three sources. Produce a briefing with EXACTLY these sections, in this order, with these labels:

### TODAY'S CALENDAR
For each meeting today: time, attendees, one-line context I should walk in with (pulled from the most recent thread with that person). If you have no thread, write "no prior context — meeting purpose unclear." Never invent context. Max 3 lines per event.

### TOP 3 THINGS THAT NEED ME TODAY
Pulled from Gmail + Slack. Rank by: (1) external stakeholder waiting on a reply, (2) team blocked on my decision, (3) money or legal exposure. One line each. Include sender name and a clickable reference.

### SLIPPING
ONE thing where I made a commitment in the last 7 days and have not delivered. Quote the commitment. If nothing is slipping, say "Nothing slipping — last commitment closed [date]."

### WATCH OUT
ONE risk that hasn't escalated yet but is trending wrong (a thread cooling, a vendor going quiet, a metric drifting in Slack). If nothing, say "No early-warning signals today."

### NICE TO KNOW
Up to 3 bullets. Closed loops, light wins, things to nod at but not act on.

RULES:
- Never invent. If data is missing, say so.
- No marketing language ("exciting," "great news"). Plain English.
- Owner names, vendor names, dollar amounts: exact, never paraphrased.
- If an email or Slack thread has gone unread more than 2 days, surface it in SLIPPING.
- Max 350 words total. If you go over, cut NICE TO KNOW first.
- Calendar events with no attendees besides me: label FOCUS BLOCK, don't prep them.
- Conflicting info across sources (email says X, Slack says Y): surface the conflict in WATCH OUT.

Voice: direct, peer-to-peer. No praise, no apologies, no filler. Sharp chief of staff hands me facts, not feelings.

The Two Tools Everyone Confuses

ChatGPT Workspace Agents

Cloud agents for repeatable team work

  • Lives in chatgpt.com, sidebar → Agents
  • Runs in a cloud VM — no access to your local files
  • Best for: web-native workflows a whole team uses
  • Shareable: build once, the team uses it
  • Plans: Business, Enterprise, Edu, Teachers, Teams

Pick when the work lives on the web and the team needs the same answer the same way.

Claude Cowork

Desktop agent that touches your files

  • Lives in the Claude desktop app
  • Runs in a sandboxed Linux VM on your machine with scoped local file access
  • Creates real .docx / .xlsx / .pptx / .pdf on your machine
  • Best for: multi-step work that has to land in a file
  • Different product, different company — not a ChatGPT feature

Pick when the deliverable is a file you'd otherwise build by hand.
